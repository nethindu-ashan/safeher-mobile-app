# SafeHer

SafeHer is a mobile application designed to support women's safety while travelling.

## Main Components

1. Safety Reporting & Emergency Assistance
2. Safe-Route Map & Navigation
3. Community Safety Alerts & Notifications
4. Safety Support Services & Nearby Help

## Tech Stack

### Mobile
- React Native
- Expo
- Expo Router

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL
- Supabase
- PostGIS

### Tools
- Jira
- GitHub
- Figma
- Postman
